## Контекст (не часть требований, для ориентира)

Существующий проект: Telegram-бот-планер (Python, `python-telegram-bot`,
Groq Whisper для голоса, Qwen 27B через Groq для разбора задач, Google Sheets
как хранилище), задеплоен на Railway, синхронизирован с GitHub
(`vololga84-ship-it/planner-bot`). Два пользователя — Оля и Мама, у каждой
свои данные. В боте только что добавлены два режима записи голосовых
заметок: «Идеи для постов» (лист «Идеи для постов») и «Заметки» (лист
«Заметки», для чего угодно — план, ответ на письмо и т.п.). Обработка
заметок сейчас идёт вручную: пользователь просит Claude Code (интерактивно,
через её Pro-подписку) прочитать лист и превратить заметки в результат.
Проблема ровно в этом: Мама может писать заметки в бота, но не может сама
попросить их обработать — доступа к Claude Code у неё нет.
