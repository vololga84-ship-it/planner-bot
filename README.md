# 🗓️ Личный Планнер — Telegram Bot

## Что умеет бот
- 🎤 Принимает голосовые сообщения (русский + английский)
- 🧠 Понимает естественную речь через Groq AI
- 📝 Уточняет категорию и дату если не сказано
- ✅ Позволяет отмечать задачи выполненными
- 📊 Трекер привычек (сон, витамины, прогулка и др.)
- 📋 Показывает задачи на день
- 📗 Записывает всё в Google Таблицу

## Команды
- `/start` — начало работы
- `/today` — задачи на сегодня
- `/done` — отметить выполненное
- `/habits` — трекер привычек
- `/goals` — цели на месяц/год
- `/menu` — главное меню
- `/table` — открыть таблицу

## Несколько участников
Каждый участник ведёт свои задачи/привычки/цели отдельно (свои листы в
таблице), но может спросить у бота про расписание другого — например
голосом «Что у Мамы сегодня?».

## Настройка

### 1. Переменные окружения (Railway)
```
TELEGRAM_TOKEN=...
GROQ_API_KEY=...
SPREADSHEET_ID=...
GOOGLE_CREDENTIALS_JSON=...
USERS=telegram_id_1:Имя1,telegram_id_2:Имя2
```
Чтобы узнать Telegram ID нового участника — пусть напишет боту `/start`,
он получит отказ в доступе с показом своего ID, который можно добавить
в `USERS`.

### 2. Google Sheets API
1. Перейдите на console.cloud.google.com
2. Создайте проект → включите Google Sheets API
3. Создайте Service Account → скачайте JSON ключ
4. Скопируйте содержимое JSON в GOOGLE_CREDENTIALS_JSON
5. Поделитесь таблицей с email сервисного аккаунта

### 3. Деплой на Railway
1. Зарегистрируйтесь на railway.app
2. New Project → Deploy from GitHub repo
3. Добавьте переменные окружения
4. Готово!
